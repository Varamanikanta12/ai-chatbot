🤖 Freko AI **(ReWOO + Document Memory)**

Freko AI is a Streamlit-based intelligent assistant that analyzes contract documents and checks for key legal clauses. It also includes a **ReWOO-style agent workflow with memory for contextual Q&A**.


🚀 Features
📄 Upload and analyze contracts (PDF, DOCX, TXT)
✅ Automatic clause validation (PASS / FAIL)
🧠 Memory-based responses (recall previous documents)
🔁 ReWOO Agent Workflow (Planner → Worker → Solver)
💬 Chat interface for interactive queries
🧑‍💻 Code detection & debugging support


🧩 Tech Stack
Frontend: Streamlit
LLM: Groq (LLaMA 3.1 8B)
Frameworks: LangChain, LangGraph
File Processing: PyPDF2, python-docx
Environment: Python, dotenv.
